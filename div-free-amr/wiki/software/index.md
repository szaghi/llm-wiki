# Software

* [ADAM](/software/adam.md) — Block-structured octree/quadtree AMR library (CPU and GPU) whose Maxwell (PRISM) and MHD (FLUME) solvers hold the divergence in two different constraint classes.
* [AMReX](/software/amrex.md) — C++ framework for block-structured AMR, successor of BoxLib: cell-, face- and node-centred data, optional subcycling, embedded boundaries, geometric multigrid, particles and MPI+X / MPI+GPU parallelism; the hierarchy under CASTRO and one of Flash-X's AMR back-ends.
* [CASTRO](/software/castro.md) — Compressible astrophysical hydrodynamics code on BoxLib/AMReX: unsplit PPM on subcycled block-structured AMR with refluxing, and a multilevel self-gravity synchronization (level solves, lagged composite correction, flux-register-driven correction solve); no divergence constraint.
