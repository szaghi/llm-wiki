# Operators

Discrete operators and their algebraic identities.

* [Divergence-space prolongation $P_D$](/operators/divergence-free-prolongation.md) — Prolongation of face magnetic fields constructed so the prolonged fine field is exactly divergence-free whenever the coarse field is.
* [SBP-preserving interpolation $I_{C2F}, I_{F2C}$](/operators/sbp-preserving-interpolation.md) — Interface interpolation pair between nonconforming SBP blocks that is adjoint in the interface norms and non-amplifying, preserving stability, accuracy, and conservation.
