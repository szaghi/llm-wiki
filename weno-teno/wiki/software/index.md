# Software

Codes and libraries embodying methods.

* [ADAM](/software/adam.md) — ADAM is a Fortran 2003 object-oriented library for block-based octree adaptive mesh refinement with immersed boundaries on GPU clusters (CUDA Fortran, CUDA-aware MPI), with NASTO, its compressible Navier–Stokes application using conservative finite-difference WENO with Lax–Friedrichs splitting; it is measured on 3D shock diffraction by a sphere on up to 256 V100 GPUs.
* [AMROC](/software/amroc.md) — Deiterding's open-source C++ framework for block-structured adaptive mesh refinement, with Clawpack-based finite-volume solvers for thermally perfect reacting gas mixtures, level-set and ghost-cell boundaries, and, since Peng et al., structured curvilinear mapped meshes.
* [FLEXI](/software/flexi.md) — FLEXI is the open-source (GNU GPL v3.0) DGSEM framework of Krais et al. for hyperbolic–parabolic conservation laws on curved hexahedra; Mossier et al. extend its a priori finite-volume subcell shock capturing to p-adaptation, Schwarz et al. compare entropy-stable Gauss–Lobatto and Gauss collocation in it for turbulent LES, and other authors position it.
* [FLUXO](/software/fluxo.md) — FLUXO is an open-source Fortran code for split-form and entropy-stable DGSEM on 3D curved unstructured hexahedral meshes, with compile-time selection of flux and degree; the sources benchmark it against Trixi.jl and use it for subcell-limiting tests on Euler, ideal and resistive GLM-MHD with non-conservative terms, up to a 20.7 M-DOF Io–plasma-torus run.
* [ForestClaw](/software/forestclaw.md) — ForestClaw is a quadtree patch-based adaptive mesh refinement code on p4est with fixed-size Cartesian patches and 2:1 balance; the bundle's sources build Active Flux solvers in it, with conservative coarse–fine transfer of averages and point values, sub-cycling without time interpolation and Berger–Colella refluxing.
* [IDEFIX](/software/idefix.md) — Lesur et al.'s performance-portable C++17 Kokkos code for astrophysical hydrodynamics and non-ideal MHD: a second-order Godunov finite-volume scheme close to PLUTO, with primitive-variable reconstruction, HLL-family and Roe solvers, constrained transport, super time-stepping and orbital advection, running the same source on CPUs and GPUs.
* [JAX-Fluids](/software/jax-fluids.md) — JAX-Fluids is an MIT-licensed Python/JAX Cartesian finite-volume solver for compressible single- and two-phase flows, fully differentiable by automatic differentiation: WENO and TENO reconstructions with Riemann solvers or characteristic flux splitting, a sharp-interface level-set method, single-GPU performance figures, and end-to-end training of a learned Rusanov dissipation.
* [MFC](/software/mfc.md) — MFC (Multi-component Flow Code) is an open-source Fortran and Python solver for compressible multi-component, multiphase and bubbly flows: five- and six-equation diffuse-interface models, finite-volume WENO with HLLC and SSP Runge–Kutta; version 5.0 adds immersed boundaries, phase change, MHD, WENO-Z and TENO, low-Mach HLLC fixes and OpenACC/OpenMP GPU offload scaled to exascale machines.
* [OpenFOAM-based compressible solvers](/software/openfoam.md) — Three sources build compressible-flow solvers in the unstructured finite-volume framework OpenFOAM: a CUDA port of a reacting-flow solver scaled to 6144 GPUs, RSDFoam coupling blastFoam numerics with Cantera real-gas thermodynamics, and a kinetic-energy-preserving central solver with Ducros-switched AUSM+-up dissipation extended to multi-species real gases.
* [PLUTO](/software/pluto.md) — PLUTO is the astrophysical finite-volume code of Mignone et al. that hosts the fourth-order pointwise constrained-transport schemes of the bundle for ideal classical and relativistic MHD and for resistive relativistic MHD, serves as data structure and MPI layer for moving-mesh and entropy-stable schemes, and is the design reference and comparison code of IDEFIX.
* [PyFR](/software/pyfr.md) — PyFR is an unstructured high-order flux-reconstruction solver for CPUs and GPUs; four papers of Dzanic and co-authors implement in it a time-reversibility artificial viscosity and a positivity- and entropy-bounded adaptive modal filter, later extended to ideal MHD and multi-species flows, run nodal DG through FR from degree 2 to 14 on mixed meshes, and report filter costs on V100 GPUs.
* [STREAmS](/software/streams.md) — STREAmS is a GPLv3 finite-difference solver for direct numerical simulation of compressible wall turbulence; version 2.0 adds an object-oriented physics/back-end split, KEEP split-form convective schemes, WENO-Z shock capturing and thermally perfect gases, and version 2.1 adds 2D-extruded curvilinear grids, OpenMP, HIP and OpenMP-offload back-ends and in situ visualization.
* [TENET](/software/tenet.md) — TENET is a modal discontinuous Galerkin code for astrophysical compressible flow; its GPU rewrite TENETGPU solves the Euler and Navier–Stokes equations on uniform Cartesian meshes with MPI and CUDA, a time-evolved artificial viscosity instead of slope limiting, recovery-based viscous fluxes, and scales to 64 A100 GPUs.
* [Trixi.jl](/software/trixi-jl.md) — Trixi.jl is an open-source Julia framework for DGSEM on Cartesian, structured and unstructured curved meshes; the sources use it for entropy-stable and kinetic-energy-preserving flux-differencing schemes, measure its serial performance against FLUXO, and run the KPP subcell-limiting test with it.
* [UCNS3D](/software/ucns3d.md) — UCNS3D is an open-source Fortran 2003, MPI and OpenMP cell-centred finite-volume code for unstructured hybrid meshes that hosts arbitrary-order least-squares WENO, CWENO and TENO reconstructions and a modal discontinuous Galerkin module; the sources use it for multicomponent interface capturing with the five-equation model, for the first unstructured TENO schemes and for hybrid DG–finite-volume schemes with troubled-cell switching.
* [URANOS](/software/uranos.md) — URANOS is a BSD-licensed Fortran 90, OpenACC and MPI finite-difference solver for compressible wall-bounded flows (DNS, wall-resolved and wall-modelled LES): a sixth-order energy-preserving central scheme hybridized with WENO-Z, TENO or adaptive TENO by a priori shock sensors, with a ghost-point immersed boundary, on GPUs.
