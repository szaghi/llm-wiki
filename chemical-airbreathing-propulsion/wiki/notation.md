# Notation registry

Every concept page of this bundle writes mathematics in the symbols below.
A source's own symbols are translated on its Source page (`# Notation map`).
The registry was seeded on 2026-10-14 from the conventions that dominate
the field's literature (SI units, freestream subscript $\infty$, total
quantities subscript $0$). Subscripts name stations and qualifiers: $\infty$ freestream, $i$ inlet,
$e$ exit, $\max$ peak value (e.g. $\mathrm{Ma}_\infty$, $p_{0,e}$, $T_{0,i}$). Extend this registry, and log the extension,
before writing a symbol it lacks.

## 1. Flow and thermochemistry

| Symbol | Meaning | Note |
|---|---|---|
| $\rho$, $\mathbf u$, $p$, $T$ | density, velocity, pressure, temperature |  |
| $Y_k$ | mass fraction of species $k$ |  |
| $\dot\omega_k$ | net production rate of species $k$ |  |
| $\phi$ | equivalence ratio |  |
| $O/F$ | oxidizer-to-fuel mass ratio |  |
| $\gamma$ | ratio of specific heats |  |
| $\dot q$ | heat-release rate (per unit volume unless stated) |  |
| $\mathrm{Ma}$ | Mach number |  |
