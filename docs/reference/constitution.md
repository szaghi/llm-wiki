::: info The repository law, verbatim
This page renders the repository's `CLAUDE.md`, the law that Claude Code loads at the start of every session in the
repository and follows as the compiler of the bundles. Each bundle adds its own `CLAUDE.md` (corpus location, domain
scope, bundle-specific conventions). The reasons behind each rule are in the [decision record](/reference/decisions);
the file itself is [on GitHub](https://github.com/szaghi/llm-wiki/blob/main/CLAUDE.md). The links shown in code below
are examples of the wiki's own link syntax, relative to a bundle root.
:::
