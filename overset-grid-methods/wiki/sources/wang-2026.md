# Summary

Lagrangian point particles moving through a multi-block overset curvilinear grid must be located in, and handed between, overlapping blocks. Wang et al. build the particle storage and redistribution on overset grid techniques: an inter-block mapping within overlapping zones, a heterogeneous zonal search-locate algorithm based on particle velocity (a [donor search](/methods/donor-search.md) for particles), and a message-passing strategy for multi-block overset grids ([parallel overset grid assembly](/methods/parallel-overset-grid-assembly.md)), which reduce tracking overhead for particles crossing block interfaces; a suite of particle-force tests is validated against newly derived analytical models.
