# Summary

Li & Wang build the Multiple Instance-Solvers Framework (MISF): one instance of a single-solver "template" code per geometrically similar component (turbine, blade, airfoil element), each on its own MPI intra-communicator, with inter-communicators between instances. Instances are coupled by dynamic [overset grid assembly](/methods/parallel-overset-grid-assembly.md) taken from Roget & Sitaraman — [implicit hole cutting](/methods/implicit-hole-cutting.md), exact-inverse-map [donor search](/methods/donor-search.md), trilinear interpolation — modified by a stricter traversal of overlapping solver/process/block triples found by bounding-box collision, a non-contiguous candidate donor list and a reworked point-type assignment with conflict resolution ([point classification](/definitions/point-classification.md)). The off-body grid is an octree Cartesian grid adapted geometrically and to flow features ([AMR on overlapping grids](/methods/amr-on-overset-grids.md)). Demonstrations: the 30P30N [multi-element airfoil](/benchmarks/multi-element-airfoil.md), arrays of vertical-axis wind turbines and a five-bladed rotor in forward flight ([moving overset grids](/methods/moving-overset-grid.md)), with timing comparisons against the authors' dual-solver code.

# Key claims

1. MISF instantiates one template-solver instance per component, on intra-communicators from `MPI_COMM_SPLIT`, with $N(N-1)/2$ inter-communicators; each component keeps its own grid and input file (§2). **Stated**
2. The overset grid assembly follows Roget & Sitaraman (implicit hole cutting, exact inverse map with stencil walking, trilinear weights by Newton–Raphson) with three modifications: a stricter traversal restricted to overlapping solver/process/block triples, a non-contiguous candidate donor list, and a reworked point-type assignment with donor suitability and availability checks and a supplementary implicit hole cutting (§3, Algorithm 5, Appendix A). **Stated**
3. The off-body octree Cartesian grid (PARAMESH) is refined geometrically by a cell-volume ratio so that background cells are not larger than the near-body cells they overlap, then adapted by a density-based shock sensor and a normalized $Q$-criterion (§4). **Stated**
4. Against the dual-solver code on the same cases MISF has lower assembly time, smaller hole maps ($35^3$ against $115^3$) and better scaling to 2880 processes, attributed to the stricter traversal (§6, Tables 2, 4). **Shown**
5. The overset assembly overhead is stated below 5 % of the total time (§7). **Stated**
6. 30P30N: surface pressure agrees with experiment; a notional flap deployment is simulated (§5.1). **Shown**

# Printed slips

- §6.2: the off-body assembly share is printed $\simeq1.8$ %; Table 2 gives $560/27705=2.02$ % *(compiler check, not in the sources)*; the summed step count 14,400 differs from 20 revolutions × 1,440 steps = 28,800.
- §7: "<5 % OGA overhead" holds for the near-body part alone; adding the background part of Table 4 gives 6.5 % *(compiler check, not in the sources)*.
- Eq. (2): only the denominator is squared, so the printed $\sigma_i$ is not dimensionless; Table 5 omits iblank values (−4, −jsolver, −1002, −2002) used in the flowcharts; in Algorithm 2 the update `j ← j + n[i]` is inside the conditional; the shaded "optimal" row of Table 4 is not the dual solver's optimum.
