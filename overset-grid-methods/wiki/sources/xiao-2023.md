# Summary

An overset grid method for unsteady multi-body aerospace flows built on parallel [implicit hole cutting](/methods/implicit-hole-cutting.md) by wall distance. Three techniques target assembly cost: a bookkeeping alternating digital tree for [donor search](/methods/donor-search.md), a parallel advancing-front algorithm for the wall-distance computation ([wall-distance hole cutting](/methods/wall-distance-hole-cutting.md)), and a message-passing strategy with lean communication and storage ([parallel overset grid assembly](/methods/parallel-overset-grid-assembly.md)). The method is embedded in an in-house URANS solver and applied to a helicopter, [store separation](/benchmarks/store-separation.md) and component deployment ([moving overset grids](/methods/moving-overset-grid.md)).

# Key claims

1. Overset assembly by parallel implicit hole cutting is accelerated by a bookkeeping alternating digital tree for the donor-cell search (Abstract, §2). **Stated**
2. A fast parallel advancing-front algorithm accelerates the wall-distance calculation that implicit hole cutting needs (Abstract, §2). **Stated**
3. A message-passing strategy lowers communication and storage on distributed architectures (Abstract, §2). **Stated**
4. Each technique is compared with existing alternatives for computing efficiency (Abstract, §3). **Shown**
5. Embedded in a URANS solver, the method resolves a helicopter, a store separation and a component deployment with the expected flow topology (Abstract, §4). **Shown**
