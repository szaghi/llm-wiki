# Summary

Conventional overset grid assembly searches donors first and classifies points afterwards. Oh et al. reverse the order: points are first classified by a wall-distance criterion (a point belongs to the grid whose wall is nearer), and the donor search then runs on the reduced set of query points. Wall distance is computed exactly against the discretized surface, made affordable by a bounded formulation and a conservative relation between vertex-based and element-based distances (approximate vertex distances first, exact element distances only where needed), plus volumetric ray tracing and octree voxelization against "distance flooding", and load balancing for spatially partitioned parallel runs ([wall-distance hole cutting](/methods/wall-distance-hole-cutting.md), [domain connectivity](/definitions/domain-connectivity.md), [parallel overset grid assembly](/methods/parallel-overset-grid-assembly.md)).

# Key claims

1. Point classification by the wall-distance criterion is performed before the donor search, which then runs on the reduced set of cells (Abstract). **Stated**
2. Wall distance is evaluated exactly against the discretized surface; efficiency comes from a bounded formulation and a conservative correlation between vertex-based and element-based distances, so the expensive exact computation is done stepwise (Abstract). **Derived**
3. Volumetric ray tracing and octree-based voxelization handle the distance flooding of the original method; load balancing adapts it to spatial-partitioning parallel runs (Abstract, Conclusions). **Stated**
4. In all test cases the algorithm is faster than post-classification assembly, including extreme proximity cases, by reducing the number of query points without changing the donor search (basic ADT) (Conclusions). **Shown**
