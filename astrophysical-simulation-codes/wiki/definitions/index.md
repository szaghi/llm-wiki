# Definitions

Precise domain terms.

* [Cell-update throughput](/definitions/cell-updates-per-second.md) — The throughput metric of grid codes — cells advanced by one full time step per wall-clock second (cell updates, zone-cycles), or its inverse, the grind time — whose value depends on what counts as one update and on the normalization (per core, socket, GPU, GCD or node), precision, scheme and problem size, which the sources state unevenly.
* [Jeans resolution criterion (Truelove condition)](/definitions/jeans-resolution-criterion.md) — The requirement that the local Jeans length be resolved by at least four cells (Truelove et al.), used as an AMR refinement criterion and, at the finest level, as the density threshold for sink-particle creation; stated to apply only to gas in self-gravitational collapse, with more cells needed for MHD.
* [Parallel scaling efficiency](/definitions/parallel-scaling-efficiency.md) — Weak-scaling efficiency (fixed work per processing unit) and strong-scaling efficiency (fixed total work) as the code papers define them, with the baselines each source uses — one core, one GPU, one node, several nodes or the smallest run that fits — on which every quoted percentage depends.
* [Reduced speed of light approximation](/definitions/reduced-speed-of-light.md) — Replacing the speed of light c by a smaller ĉ = f_c c in the time derivatives of explicit radiation moment equations to relax the light-speed time step, with two validity criteria (ionization-front propagation in RAMSES-RT; time-scale ordering in Hyperion), and Quokka's finding that a closed system then relaxes to a biased equilibrium, about 20 % too hot at ĉ = 0.1c.
