# Software

Codes embodying methods.

* [ADAM (GPU block-octree AMR library) and NASTO](/software/adam.md) — Fortran 2003 object-oriented library for block-based octree AMR on Cartesian grids whose compute phase runs entirely on NVIDIA GPUs through CUDA Fortran with CUDA-aware MPI, with the octree kept serially on the CPU in a hash map; its NASTO application solves the compressible Navier–Stokes equations with WENO finite differences, Lax–Friedrichs flux splitting, SSP RK3 and an immersed boundary.
* [Athena (astrophysical MHD code)](/software/athena.md) — Second-order, directionally unsplit Godunov code for compressible ideal MHD and hydrodynamics in C and Fortran 95, with face-centred upwind constrained transport, CTU+CT and VL+CT integrators, HLLE/HLLC/HLLD/Roe solvers and MPI domain decomposition, extended by the two-moment M1 radiation module Hyperion.
* [Athena++ (block-based AMR framework for astrophysical MHD)](/software/athena-plus-plus.md) — C++ rewrite of Athena around a physics-agnostic block-based tree AMR mesh with a single global time step and task-list execution, carrying finite-volume upwind-CT MHD (Newtonian, special and general relativistic) with method-of-lines integrators, a multigrid self-gravity solver and a fully conservative self-gravity coupling.
* [AthenaK (performance-portable Kokkos version of the Athena++ AMR framework)](/software/athenak.md) — From-scratch Kokkos C++ reimplementation of the Athena++ block-based AMR framework that keeps all field data device-resident, packs every MeshBlock of a device into one MeshBlockPack, runs on CPUs and NVIDIA, AMD and ARM hardware, and carries Newtonian, special- and general-relativistic (M)HD, two-fluid ion–neutral MHD, discrete-angle GR radiation and particles.
* [CASTRO (compressible astrophysics code on BoxLib AMR)](/software/castro.md) — BoxLib-based C++/Fortran 90 code for multicomponent compressible hydrodynamics with a general equation of state, reactions and self-gravity, using an unsplit PPM Godunov method with full corner coupling and a two-shock-type Riemann solver on subcycled Berger–Oliger patch AMR with refluxing and a multilevel Poisson synchronization.
* [Cholla (GPU-native astrophysical MHD code)](/software/cholla.md) — GPU-native finite-volume code on a static uniform Cartesian mesh, in C++ with CUDA or HIP, whose MHD extension runs the VL+CT integrator with HLLD fluxes, characteristic PLM or PPM and Gardiner–Stone constrained transport entirely in GPU memory and weak-scales to 74,088 MI250X GCDs of Frontier, and whose cosmology extension adds super-comoving coordinates, FFT self-gravity, particle-mesh dark matter, a dual-energy formalism and Grackle chemistry on the host.
* [Enzo (AMR code for cosmological and astrophysical fluid flow)](/software/enzo.md) — Open-source Cartesian patch-based AMR code in comoving coordinates (version 2.3) with four interchangeable fluid solvers (split PPM, unsplit MUSCL with GLM cleaning, constrained-transport MHD, ZEUS), the dual-energy formalism, subcycled level-by-level time stepping with flux correction, FFT plus grid-by-grid multigrid gravity, and coupled N-body, chemistry, cooling and radiation.
* [FLASH](/software/flash.md) — Block-structured AMR code on the PARAMESH library, documented here through two star-formation papers: an HLL5R MHD solver, multigrid self-gravity after Ricker (2008), Jeans-length refinement, accreting sink particles with creation checks and (in the 2021 configuration) intrinsic spin, a barotropic piecewise-polytropic closure, and turbulence-driving and protostellar-feedback sub-grid modules.
* [GAMER (GPU-accelerated octree AMR code), MHD extension](/software/gamer.md) — GPU-accelerated octree patch-based AMR code whose MHD extension runs Athena's CTU+CT and VL+CT unsplit schemes on the GPU per group of eight patches, keeps the divergence-free constraint across levels with Balsara prolongation and EMF correction, and overlaps GPU work with CPU-side AMR operations under hybrid MPI/OpenMP/GPU parallelism.
* [gPLUTO](/software/gpluto.md) — Complete C++ rewrite of the PLUTO MHD code that runs the whole time step on NVIDIA GPUs through OpenACC, described so far for ideal MHD on uniform Cartesian grids (SSP-RK3, WENOZ or parabolic reconstruction, HLLD, upwind constrained transport or GLM cleaning), with weak and strong scaling to 256–512 nodes and a GPU-frequency energy study.
* [Grackle (chemistry and cooling library)](/software/grackle.md) — Open-source C/Fortran library, extracted from Enzo, that advances non-equilibrium primordial chemistry (6, 9 or 12 species) and radiative cooling and heating point by point inside a host code's time step, with a sequential first-order backward-difference update sub-cycled under a 10% change limit, Cloudy metal-cooling tables, dust, UV backgrounds and self-shielding, used by 14 host codes.
* [GRaM-X](/software/gram-x.md) — GPU-accelerated dynamical-spacetime GRMHD code for the Einstein Toolkit: Z4c spacetime on vertices and Valencia GRMHD on cells, TVD or WENO5 reconstruction with HLLE fluxes, a 3D Newton–Raphson / Newman / temperature-bisection primitive-recovery chain, tabulated nuclear EOS in unified memory, and block-structured AMR without subcycling through the CarpetX driver on AMReX, with all data kept on the GPU.
* [H-AMR](/software/h-amr.md) — GPU-accelerated GRMHD code rewritten from HARM, hybrid CUDA–OpenMP–MPI, with AMR and locally adaptive time stepping; in the EHT code comparison it ran second-order PPM with HLL and upwind constrained transport, static azimuthal de-refinement near the pole and drift-frame floors, and its throughput is quoted as 0.85e8 zone-cycles/s on one V100 and 3–5e8 zone-cycles/s per GPU including the time-stepping speed-up.
* [IDEFIX (performance-portable Godunov code for astrophysical flows)](/software/idefix.md) — Kokkos C++ finite-volume Godunov code for non-relativistic HD and MHD, PLUTO-compatible in its inputs, with primitive reconstruction up to PPM, five Riemann solvers, face-centred constrained transport with an optional vector-potential form, method-of-lines RK integrators, RKL2 super-time-stepping, non-ideal MHD and conservative orbital advection on Cartesian, cylindrical and spherical non-AMR grids, run fully on the device.
* [Neko (portable spectral-element framework for incompressible flow)](/software/neko.md) — Object-oriented Fortran 2008 matrix-free spectral-element framework for incompressible flow, built on the numerical methods of Nek5000, that reaches CPUs, vector engines, GPUs and FPGAs through backend-specific extensions of abstract Fortran types instead of an external portability library; described here from the 2021 preprint.
* [PLUTO (multiphysics code for astrophysical gas dynamics, with Chombo AMR)](/software/pluto.md) — Godunov-type code for Newtonian and relativistic MHD whose adaptive version couples a cell-centred, dimensionally unsplit second-order CTU scheme with GLM divergence cleaning to the Chombo patch-based AMR library, with subcycling, refluxing, unsplit parabolic terms and a leaf-cell time step for stiff local sources.
* [Quokka](/software/quokka.md) — GPU-native block-structured AMR radiation hydrodynamics code on AMReX: method-of-lines RK2-SSP hydrodynamics with PPM and HLLC, gray two-moment radiation with a reduced speed of light, a pluggable local Eddington-factor closure and HLL fluxes, explicit radiation subcycled per level, and a local Newton–Raphson matter–radiation exchange.
* [RAMSES-RT (radiation hydrodynamics in RAMSES)](/software/ramses-rt.md) — Multigroup radiative transfer of ionizing photons built into the cell-based oct-tree AMR code RAMSES: M1-closed photon-number moment equations advanced by an explicit first-order HLL or global Lax–Friedrichs scheme under a reduced speed of light, operator-split from a quasi-implicit non-equilibrium H/He thermochemistry, and multi-stepped across AMR levels with the hydrodynamics so that photons are conserved.
* [STREAmS (GPU finite-difference DNS solver for compressible wall turbulence)](/software/streams.md) — Cartesian finite-difference DNS solver for the compressible Navier–Stokes equations, hybridizing an energy-preserving central flux with Lax–Friedrichs flux-vector-split WENO under a Ducros shock sensor, with low-storage RK3, kept in one Fortran source for CPUs and multi-GPU runs through CUDA Fortran kernels, device-resident data and optional compute–communication overlap.
* [TIGRESS (Athena framework for the star-forming shearing-box ISM)](/software/tigress.md) — Set of physics modules in the Athena MHD code for a vertically stratified, self-gravitating, magnetized shearing-box patch of a galactic disc: implicit sub-cycled cooling with time-variable FUV heating, Larson–Penston-threshold sink/star particles with a symplectic shearing-box integrator, stochastic supernovae with a resolution-adaptive three-way feedback prescription, verified by module unit tests and a 2–64 pc resolution study.
