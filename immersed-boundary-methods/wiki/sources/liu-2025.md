# Summary

Liu, Jiang, Shu and Zhang apply the [inverse Lax–Wendroff](/methods/inverse-lax-wendroff.md) procedure to deformable solids. The fluid ghost values and the solid's interface fluxes come from one linear system for the normal derivatives built from both media's PDEs and the interface conditions, giving third order without remeshing or sub-iterations, and stability across density ratios where weakly coupled ILW fails ([fluid–structure coupling](/methods/fluid-structure-coupling.md)).

# Key claims

1. ILW had treated rigid bodies with weak coupling only; this is its first application to deformable solids (§1). **Stated**
2. Both media's PDEs and the interface conditions yield one system for the normal derivatives, hence fluid ghost values and solid fluxes at third order (§3). **Derived**
3. The treatment is stable for density ratios $10^{-2}$, $1$, $10^{2}$; weakly coupled ILW is unstable at $10^{2}$ (§4). **Shown**
4. Third-order accuracy for smooth solutions and oscillation-free shock-induced interaction (§5). **Shown**
