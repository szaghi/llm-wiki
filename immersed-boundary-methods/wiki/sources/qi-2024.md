# Summary

Qi et al. combine DG (with direct DG for viscous terms) on p4est-managed adaptive Cartesian grids, a compact multi-resolution WENO limiter, and a [ghost-cell](/methods/ghost-cell-method.md) immersed boundary. The image-point value is taken from the DG polynomial of the cell containing it, avoiding wide interpolation stencils ([high-order immersed boundary treatments](/methods/high-order-immersed-boundary.md)). Tests run from Couette flow to the ONERA M6 wing and a transonic sphere.

# Version read

Version of record, Phys. Fluids 36, 116139 (2024). §§1–3 read, §4 tests in outline.

# Key claims

1. Image-point values from the host cell's DG polynomial avoid the wide stencils of traditional immersed boundary interpolation (§3). **Stated**
2. The multi-resolution WENO limiter barely changes errors in smooth regions (§4). **Shown**
3. The method handles airfoils, the ONERA M6 wing and a viscous sphere on parallel adaptive grids (§4). **Shown**
