# Software

Codes embodying methods.

* [BOUT++](/software/bout-plus-plus.md) — Finite-difference framework for plasma fluid equations in curvilinear geometry that stores fields in field-aligned coordinates and takes derivatives in the quasi-ballooning (shifted-metric) system; Seto et al. add a solver that inverts the perpendicular operator per toroidal mode in orthogonal flux coordinates for n = 0 and low n.
* [GMEC](/software/gmec.md) — Gyrokinetic-MHD energetic-particle code family (Zhejiang University): reduced MHD in global field-aligned coordinates with arbitrary-order finite differences in all three directions, Scott's or a simple shifted metric, metrics and their derivatives precomputed from the equilibrium, and discrete equations generated symbolically at compile time.
