# Methods

Algorithms and schemes.

* [Shifted metric](/methods/shifted-metric.md) — Local re-coordinatisation of field-aligned grids: on each grid plane ξ^2 = const the binormal coordinate is shifted, ξ̄^3 = ξ^3 − σ_k(ξ^1) on plane k, so that the radial derivative no longer carries the integrated shear; Scott's choice makes ḡ^13 = 0, the simple variant makes ξ̄^3 the toroidal angle, and the quasi-ballooning form of BOUT++ pairs it with a shifted radial derivative. It removes the instability that the metric discontinuity at the twist-shift boundary drives.
