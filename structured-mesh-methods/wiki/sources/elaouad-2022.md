# Summary

El Aouad, Larcher and Hachem turn an immersed geometry into a body-fitted anisotropic mesh by [anisotropic mesh adaptation](/methods/anisotropic-mesh-adaptation.md) followed by a geometric fitting step.

# Version read

HAL deposit hal-03942147 (author manuscript); metadata from the version of record, Comput. Methods Appl. Mech. Eng. 400, 115562 (2022). Abstract, method sections and conclusions read; test cases in outline.

# Key claims

1. A metric from level-set gradients stretches elements along the interface (method). **Stated**
2. Relocating the nodes closest to the interface and swapping edges of cut elements yields a body-fitted mesh with unchanged node and element counts (method, conclusions). **Shown**
