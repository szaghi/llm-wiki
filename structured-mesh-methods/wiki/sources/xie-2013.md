# Summary

Xie et al. curve a straight-sided mesh by solving a linear elasticity problem whose loads move the high-order boundary nodes onto the true surface ([high-order mesh curving](/methods/high-order-mesh-curving.md)), and assess validity with a signed scaled Jacobian ([validity](/definitions/high-order-mesh-validity.md)).

# Version read

Version of record, Comput. Mech. 51, 361–374 (2013; online 2012). §§1–4 and §6 read; §5 examples in outline.

# Key claims

1. A posteriori curving is preferred to direct methods because it reuses mature linear meshers (§1). **Stated**
2. Boundary displacements onto the NURBS surface as Dirichlet data of a linear elastic problem curve the interior (§2–§4). **Stated**
3. Element quality depends strongly on Poisson's ratio, not on Young's modulus; $\nu=0.4$ is used (§4–§5). **Shown**
4. Anisotropic wing–body meshes with stretching above 200 are curved validly (§5). **Shown**
