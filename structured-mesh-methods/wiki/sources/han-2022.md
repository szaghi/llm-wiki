# Summary

Han, Xu and Liu make the discrete-equivalence approach to [free-stream preservation](/properties/free-stream-preservation.md) usable by any upwind scheme: the full transformed equations are solved and, by freezing metrics within each stencil, flux and source term share one operator ([conservative metric evaluation](/methods/conservative-metric-evaluation.md)).

# Version read

Version of record, Phys. Fluids 34, 116111 (2022). §I and §V read; §§II–III by structure; tests in outline.

# Key claims

1. The discrete source term of the full equations is not zero even with analytic metrics (§II). **Shown**
2. Fluxes and source-term derivatives must use the same operator and consistent splitting; frozen metrics achieve this without changing the scheme (§III, §V). **Derived**
3. WENO5 with the method on low-quality meshes beats plain WENO5 on high-quality meshes in a channel-bump test (§IV). **Shown**
