# Summary

Su et al. reformulate the upwind dissipation so that it vanishes for uniform flow whatever the metric discretization ([conservative metric evaluation](/methods/conservative-metric-evaluation.md)).

# Version read

arXiv:2101.05886v1 (13 January 2021, preprint submitted to Elsevier); metadata from the version of record, J. Sci. Comput. 96, 73 (2023). Abstract, introduction and method by structure read.

# Key claims

1. Subtracting a reference cell-face state from the stencil values preserves the free stream without changing the scheme (abstract). **Stated**
2. Metrics and fluxes need not share a discretization (abstract). **Stated**
3. The metric order has no significant influence on results unless the mesh is very fine (validations). **Shown**
