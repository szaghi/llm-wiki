# Software

Codes and libraries embodying methods.

* [NekMesh (open-source high-order mesh generator)](/software/nekmesh.md) — Open-source generator of valid curvilinear high-order meshes for spectral/hp element simulation: a CAD-independent pipeline of modules that meshes from CAD or curves linear meshes from many formats, splits a thick curved prism layer into boundary-layer elements, and optimizes and untangles meshes in a variational framework that generalizes elastic and Winslow models.
