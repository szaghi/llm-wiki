# Software

Codes and libraries embodying methods.

* [CharLES](/software/charles.md) — CharLES is Cascade Technologies' compressible, low-dissipation, second-order finite-volume LES code on Voronoi grids; this page records its scheme, meshing, GPU cost and the wall-modelled LES of aircraft, juncture flows, bumps and compressible channels run with it, including machine-learning wall models trained in it.
* [FLEXI](/software/flexi.md) — FLEXI is an open-source high-order DGSEM framework for compressible scale-resolving simulation, with the HOPR mesh generator and POSTI post-processing; this page records its numerics, turbulence features, parallel performance and the LES studies run with it.
* [GALÆXI](/software/galaexi.md) — GALÆXI is the GPU port of the FLEXI DGSEM framework in CUDA Fortran for compressible flow on curved unstructured hexahedra, with split-form DG and subcell finite-volume shock capturing; this page records its kernel and stream design, memory, scaling to 1024 A100 GPUs, verification and energy-to-solution against FLEXI.
* [GHOST](/software/ghost.md) — GHOST (Geophysical High-Order Suite for Turbulence) is a pseudo-spectral community code with hybrid MPI/OpenMP/CUDA parallelism, second-order Runge–Kutta time stepping and two-thirds de-aliasing; in the sources it runs decaying compressible Hall-MHD DNS and serves as the reference for a lattice Boltzmann MHD code.
* [HORSES3D](/software/horses3d.md) — HORSES3D is an open-source Fortran DGSEM framework for compressible and incompressible flow with RANS, explicit and implicit LES, shock capturing, multiphase, particles, aeroacoustics and immersed boundaries; this page records its numerics, turbulence options including jump-penalty implicit LES, adaptation, solvers and parallel performance.
* [LESGO](/software/lesgo.md) — LESGO is an open-source incompressible LES code, pseudo-spectral in the wall-parallel directions and second-order finite-difference on a staggered wall-normal grid, used as the host of wall-model studies: the LaRTE model, an a posteriori comparison of machine-learning wall models, and the training of a reinforcement-learning wall model coupled to the Smarties library.
* [Nek5000 and NekRS](/software/nek5000.md) — Nek5000 is Argonne's open-source continuous spectral element solver for incompressible flow, and NekRS its GPU successor in C++/OCCA; this page records the shared formulation, NekRS's GPU kernels, preconditioning and scaling to all of Summit, and wall-modelled LES with Nek5000.
* [Nektar++](/software/nektar-plus-plus.md) — Nektar++ is an open-source spectral/hp element framework with continuous and discontinuous Galerkin solvers; this page records the incompressible and acoustic solvers, stabilizations (spectral vanishing viscosity, gradient-jump penalisation), meshing and costs used by the scale-resolving and aeroacoustic studies of the bundle.
* [OpenCFD-SCU](/software/opencfd-scu.md) — OpenCFD-SCU is an open-source CUDA-C/HIP finite-difference code for DNS of compressible wall-bounded turbulence, ported from the CPU code OpenCFD-SC; this page records its numerics, parallel and GPU design, reported performance and its 31-billion-point compression-ramp DNS.
* [OpenFOAM](/software/openfoam.md) — OpenFOAM is the open-source unstructured finite-volume toolbox that many bundle sources use as baseline RANS solver for data-driven closures, as second-order LES solver and as host of in-house solvers; this page records the solvers, schemes and versions they report and what the comparisons with high-order codes say about its dissipation.
* [ProLB](/software/prolb.md) — ProLB is a lattice Boltzmann solver on octree Cartesian grids with a regularized collision, eddy-viscosity closures and immersed boundaries; in the sources it runs wall-modelled LES of the Ahmed body, LES of turbulent fluid–structure interaction, and k-ω SST RANS and SST-based hybrid RANS/LES of airfoils and the Ahmed body.
* [RAMSES](/software/ramses.md) — RAMSES is an octree adaptive-mesh-refinement code with a second-order Godunov MHD solver and constrained transport; in the sources it hosts cosmological galaxy-formation runs whose dissipation is purely numerical, a one-equation subgrid turbulence model, a subgrid dynamo, and a comparison of refinement strategies for the turbulent dynamo.
* [Relexi](/software/relexi.md) — Relexi is the open-source reinforcement-learning framework of the FLEXI group that trains turbulence-model policies on HPC systems by launching FLEXI LES as environments and exchanging states and actions through SmartSim; this page records its components, training settings and the hardware and costs reported.
* [STREAmS](/software/streams.md) — STREAmS is an open-source multi-GPU finite-difference solver for compressible wall-bounded flows on Cartesian grids, combining energy-preserving central schemes with WENO shock capturing; this page records its numerics and its use for supersonic and hypersonic boundary-layer DNS and for implicit LES of a capsule wake with immersed boundaries.
* [TRACE](/software/trace.md) — TRACE is DLR's turbomachinery flow solver, with a second-order finite-volume solver for RANS, URANS and DDES and a high-order DGSEM solver for implicit LES; this page records the configurations, transition and Reynolds-stress closures, inflow generation, flux blending and costs reported by the cascade studies of the bundle.
* [elsA](/software/elsa.md) — ONERA's compressible cell-centred finite-volume solver for structured multi-block grids, as used in the sources: host of the zonal detached-eddy simulation of a turbofan fan stage, structured Spalart–Allmaras RANS reference for NASA Rotor 37, and a recalled URANS and wall-resolved reference for buffet and airfoil studies.
