# Summary

A simpler fifth-order WENO on the same five points as WENO-JS, with
unequal stencils: one quartic and two linear polynomials. The subtraction
of the small polynomials from the large one (with the linear weights) is
what keeps fifth order for any positive linear weights. Merged into
[adaptive-order WENO](/methods/weno-ao.md) and benchmark pages.

# Key claims

1. **Polynomials** (Step 1): quartic on $T_1$, linear on $T_2$, $T_3$.
2. **Linear weights** (Step 2): any positive set summing to one;
   $0.98, 0.01, 0.01$ used.
3. **Indicators** (eqs. 2.11–2.16) and $\tau$, weights (eqs. 2.19–2.20),
   $\omega - d = O(h^4)$, also at $f' = 0$; $\varepsilon = 10^{-6}$.
4. **Reconstruction** (eq. 2.22) with the subtraction; near
   discontinuities a TVD scheme with a van Albada-like limiter.
5. **Tests** (CFL 0.6, RK3): Burgers 1D/2D and smooth Euler with three
   weight sets (lower errors and CPU than WENO-JS), Lax, Shu–Osher, blast
   waves, double Mach, forward step. Seventh and ninth order possible but
   not sharper.
