# Summary

A sixth-order WENO that recovers the non-dissipative central scheme in
smooth regions and the classical upwind WENO near discontinuities,
without a separate detector. Merged into
[central-upwind WENO](/methods/central-upwind-weno.md) and benchmarks.

# Key claims

1. **Central six-point flux** (eq. 16) and downwind candidate (eq. 20);
   $d = (1, 9, 9, 1)/20$; sixth order if $\omega - d = O(h^4)$ (eq. 23).
2. **Weights** (eq. 24): $d_k(C_w + \tau_6/(\beta_k + \varepsilon))$,
   $C_w = 20$, $\varepsilon = 10^{-40}$; $\beta_3 \to \beta_6$ (eq. 25);
   $\tau_6 = \beta_6 - (\beta_0 + \beta_2 + 4\beta_1)/6 = O(h^6)$ (eqs. 26–27).
3. Degenerates at critical points; the Borges fix declined as too
   dissipative.
4. **Tests** (RK3, LF flux, Roe characteristics): Gaussian advection
   (sixth order), Sod, Lax, 123, blast waves, Shu–Osher, isentropic
   vortex, Mach 8 shock–vorticity, double Mach, equipartition spectrum.
