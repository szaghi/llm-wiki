# Software

Codes embodying methods.

* [EX-PWS](/software/ex-pws.md) — Beihang University's three-dimensional hybrid PIC-DSMC plume code on unstructured tetrahedral grids, with macroparticle heavy species, isothermal Boltzmann electrons, untracked background gas and Maxwell-reflection surfaces, validated on ion-thruster plume force against a torsional micro-thrust balance.
* [HYPHEN](/software/hyphen.md) — Axisymmetric hybrid code of the UC3M EP2 group that couples a particle model of the heavy species with a drift-diffusion electron fluid on a magnetic-field-aligned mesh, applied to magnetically shielded Hall thrusters and electron-cyclotron-resonance thrusters.
* [WarpX](/software/warpx.md) — Open-source GPU-native particle-in-cell code from the US DOE Exascale Computing Project, applied with Python callbacks to the axial–azimuthal Hall-thruster benchmark, where one H100 completes the 20 µs case in 1.81 days and its multigrid electrostatic solver limits multi-GPU scaling.
