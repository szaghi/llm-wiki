# Operators

Discrete operators and their algebraic identities.

* [Five-point discrete Laplacian](/operators/five-point-laplacian.md) — Second-order central-difference approximation of the two-dimensional Laplacian on a rectangular grid with spacings Delta x and Delta y; with Dirichlet values on the perimeter it turns Laplace's equation into a linear system for the interior grid values, and a nine-point variant is posed as an exercise.
